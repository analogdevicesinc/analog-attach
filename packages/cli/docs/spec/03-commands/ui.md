# ui (withdrawn)

The hidden `ui [--port <number>] [--open]` command, a proof-of-concept
browser page over a local HTTP API, is gone: `analog-attach ui` is an
unknown command (GRM-004).

The requirements of this chapter are *withdrawn*: UI-001, UI-002, UI-003,
UI-004, UI-005, UI-010, UI-011, UI-012, UI-013, UI-014, UI-015, UI-016,
UI-017, UI-020, UI-021, UI-030, UI-031, UI-032, UI-033, UI-034, UI-035,
UI-036, UI-040, UI-041, UI-042, UI-043, UI-044 and UI-045. Its open issues
U-2 to U-8 are closed with it.
