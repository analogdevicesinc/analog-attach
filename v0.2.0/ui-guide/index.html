    GUI Guide

    The GUI is served by the CLI and opened in a browser. Every action in the GUI runs an analog-attach command, and the console at the bottom of the page shows each one, so what you do in the GUI you can also do on the command line.

    • Starting
    • Workspace
    • Adding devices
    • Editing
    • Validate, build and deploy
    • Error reporting

    • Starting: start and stop the GUI, and set up a project.

    • Workspace: the parts of the page, the settings and the assistant.

    • Adding devices: find a device and add it to the overlay.

    • Editing: properties, child nodes, enable, rename, move and delete.

    • Validate, build and deploy: validation, build, deploy, and the board’s settings.

    • Error reporting: where the GUI shows errors and warnings.
