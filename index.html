    Analog Attach

    Analog Attach is a command line tool, with a GUI that runs locally in your browser, for attaching devices to Linux boards through devicetree overlays. It works with any device that has a Linux driver and a devicetree binding. It writes the overlay for you, validates it against the bindings of your Linux kernel tree, builds it and deploys it to the board. For boards without overlay support it builds a full devicetree instead. An AI agent can drive it too: it ships a skill for AI coding agents, and the GUI has an Assistant.

    Analog Attach is distributed as an npm package attached to each release on GitHub. The source code is available at ADI analog-attach repository.
